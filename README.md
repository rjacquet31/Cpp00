# C++ Module 00

> **42 cursus** · C++ · object-oriented programming module.

Part of the C++ learning modules at 42. Namespaces, classes, member functions, stdio streams, initialization lists and basic I/O.

## Features

- Multiple exercises (`ex00`, `ex01`, …), each in its own folder
- Compiled with `c++ -Wall -Wextra -Werror -std=c++98`

## Build

```bash
cd ex00 && make    # build a single exercise
```

## Usage

```bash
./<exercise_executable>
```

## Key concepts

First steps in C++ and object-oriented basics.
